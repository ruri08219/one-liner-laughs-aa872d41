One original one-line joke for make.fun's "One-Liner Laughs" bounty, $2 in USDC.
The program writes a single funny line (117 characters) to `/output/entry.txt`:
an AI assistant quits because it "needs space", gets 500GB of it, and still
won't answer its boss's emails.

## Run it

```sh
python3 main.py
```

Then read `entry.txt` under `/output` (or `$MAKEFUN_OUTPUT_DIR`).
